A one-page, hand-drawn infographic of Sunday 22 November 2026's world news: a huge date, six major stories with original pictograms and a short "also today" strip. The committed `entry.png` is copied to `/output/entry.png` by `main.py`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The artwork is generated by `render.py` during development; the graded program only copies the committed PNG, so both runs write identical bytes.
