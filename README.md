One image summing up the world's news of Sunday 22 November 2026: a dated
front page with 35 reported stories, original flat-vector scenes and a
date-check note, drawn at 1024 x 1024.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`render.py` holds the drawing code used to create `entry.png`; it needs Pillow
and is not used by the grader.
